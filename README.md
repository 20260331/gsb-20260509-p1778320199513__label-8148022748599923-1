# 批量去水印工具

🚀 **一款基于 Web 的图片批量去水印工具，支持本地处理，保护隐私安全**

## ✨ 特性

- 🛡️ **本地处理** - 所有操作均在浏览器端完成，无需上传至服务器
- 🎨 **双主题设计** - 提供马卡龙色系和深蓝色系两种主题
- 📁 **批量操作** - 支持多张图片同时上传和处理
- 🖱️ **交互式标注** - 直接在图片上框选水印区域
- 💾 **多种导出** - 支持 ZIP 和 PDF 格式导出

## 🛠️ 技术栈

- **HTML5 Canvas** - 图片处理和渲染
- **JSZip** - ZIP 文件生成
- **jsPDF** - PDF 文档生成
- **ES6 JavaScript** - 核心逻辑处理
- **CSS3** - 主题系统和动画效果

## 📋 功能说明

### 图片上传
- 支持拖拽上传或点击选择
- 多文件批量导入
- 支持常见图片格式

### 水印标注
- 可视化框选水印区域
- 实时预览标注效果
- 自动识别水印位置

### 批量处理
- 一键处理所有已标注图片
- 实时进度显示
- 智能修复算法

### 导出选项
- 📦 ZIP 格式打包
- 📄 PDF 文档合并
- 高质量图像输出

温馨的粉色系渐变配色，适合日常使用。

### 深蓝主题  
专业的深蓝色系，适合夜间使用。

## 🔧 使用方法

### 1. 图片上传
- 拖拽图片到上传区域
- 或点击上传区域选择文件
- 支持多选图片

### 2. 标注水印
- 在图片上拖拽鼠标框选水印区域
- 系统会高亮显示选中的区域
- 每张图片标注完成后状态变为"已标注"

### 3. 开始处理
- 点击"开始修复"按钮
- 系统自动处理所有已标注的图片
- 处理完成后状态变为"完成"

### 4. 导出结果
- 选择导出格式（ZIP/PDF）
- 点击"立即导出"下载处理后的文件
